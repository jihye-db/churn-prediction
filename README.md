# 고객 이탈 예측 (Customer Churn Prediction)

고객 한 명 한 명의 정보(사용량, 만족도, 결제수단, 가입기간, 상담 횟수 등)를 보고, 이 사람이 곧 떠날 고객인지(이탈=1) 계속 남을 고객인지(유지=0)를 맞히는 모델을 만드는 머신러닝 프로젝트. 이탈이 전체의 10.7%뿐인 불균형 데이터라 평가지표는 Macro F1을 썼고, 학습 69,860명, 테스트 30,140명 규모였다.

## 데이터 전처리
- 결제수단 표기가 Credit Card, CreditCard, CREDIT CARD처럼 8가지로 흩어져 있어 카드·계좌이체·전자지갑 3종으로 통일했다.
- 사용량 -999, 월요금 9999.99처럼 숫자로 위장한 결측값(센티널)을 찾아 결측 처리했다.
- 결측 대치 기준(중앙값)은 학습 데이터로만 계산해 테스트 정보가 새지 않게 했다.

## EDA에서 찾은 핵심
만족도가 비어 있는 고객의 이탈률이 87.8%, 만족도가 있는 고객은 4.6%였다. 설문에 응답하지 않은 것 자체가 이미 마음이 떠난 신호였고, 이 발견이 모델 성능의 핵심이 됐다.

## 파생변수
EDA에서 찾은 신호를 변수로 만들었다. 만족도·요금·사용량 결측 여부 플래그, 가입기간·마지막 로그인 경과일 같은 날짜 파생, 가입기간 대비 상담 횟수·요금 부담 같은 비율 변수 등 총 24개를 만들었다. 감으로 넣지 않고 교차검증에서 실제로 점수가 오르는 것만 최종으로 채택했다.

## 모델
정형 데이터에 강한 부스팅이 맞다고 보고 HistGradientBoosting을 주력으로 삼았다. 부스팅 모델끼리는 예측이 비슷해 섞는 효과가 없어서, 계열이 다른 ExtraTrees와 LogisticRegression을 일부러 넣어 서로 다른 실수를 하도록 구성했다. 세 모델의 이탈 확률을 평균 내 최종 예측으로 썼다. 검증은 Stratified 5-Fold로 이탈 비율을 유지하며 나누고, 학습에 안 쓴 데이터로만 예측을 모아(OOF) 부풀려지지 않은 점수를 얻었다.
